积存金 1.0.0 — macOS 15 菜单栏报价工具

安装：把「积存金.app」拖入 Applications，再双击启动。
也可直接运行 dist/积存金.app。不会显示 Dock 图标；查看屏幕顶部右侧菜单栏。
Apple Silicon 和 Intel 通用二进制，macOS 15.0 及以上。

菜单栏显示工行「实时主动积存价格」，人民币元/克，保留两位小数。
点击报价可选择「设置…」或「退出」。关闭设置窗口不会退出应用。
刷新间隔可选 10 / 15 / 20 / 30 / 60 秒，默认 30 秒，保存后生效。

低价和高价提醒可单独开启，也可同时开启。
输入价格后点击「保存设置」，首次使用请在系统授权弹窗允许通知。
严格低于/高于才提醒，相等不提醒；持续超限只提醒一次，回到范围再越界才重新提醒。
启动或修改阈值会重新判断；只改变刷新间隔不会重置提醒状态。
「发送测试通知」可检查通知权限。专注模式、通知样式可能影响通知的显示和声音。
应用未运行、Mac 睡眠、断网时不会监测价格；唤醒后会重新获取。

网络失败：显示上次报价并加「!」，未获取过则显示「--.--」。
悬停查看错误及最近成功获取时间。旧报价不触发提醒，后续自动重试。
「最近获取」是本机抓取成功时间，不是交易所或工行报价更新时间。
工行页面本身以 60 秒定时刷新；更短的抓取间隔不保证更高行情更新频率。
只使用公开网页，无需银行账号，不登录、不交易。
价格仅供参考，交易以工行实际报价为准；本软件非工行官方产品。
数据源：https://mybank.icbc.com.cn/icbc/newperbank/perbank3/gold/goldaccrual_query_out.jsp

本构建为本地 ad-hoc 签名，未使用 Apple Developer ID 签名或公证。
若 macOS 阻止打开：先尝试打开一次，再到「系统设置 → 隐私与安全性」选择「仍要打开」。
无需关闭 Gatekeeper 或更改整个系统的安全设置。

开发与验证（需 Apple Command Line Tools / Swift 6）：
swift run CoreTests --live
swift run UITests
python3 scripts/build.py
